# MailFlare
<hr>
A web app for your bulk emailing problems with safety.

## To run the project run the following commands
<ol>
  <li>Install the node modules</li>
  
  ```bash
  npm install
  ```
<li>
    Build the project
</li>
  
  ```
  npx tsc
```

  <li>
    Start the backend Server
  </li>
  
  ```
  npm run start
```
  
</ol>
